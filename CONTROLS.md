# Controls

**Azeroth Survivors** — top-down, one hand on WASD, the other on the wheel.

| When | Key / Input | Action |
|---|---|---|
| Menu | Click a race, gender, class and zone | make your pick (**Randomize** rolls one) |
| Menu (Co-Op Lobby) | Click the IP box, type `IP:Port`, click **Host** or **Join** | host a LAN / ZeroTier / Tailscale party or connect to a host (default port `25565`) |
| Menu (Client) | **Enter** (or **Ready / Unready**) | toggle your ready status in the party lobby |
| Menu (Host / Solo) | **Enter** (or **Enter World**) | start the run for the party (once all clients are Ready) |
| Playing | **W / S / A / D** or **arrow keys** | move the hero (locked camera: the hero faces the cursor, backpedals and strafes) |
| Playing | **Space** | jump |
| Playing | **F** (from level 5) | your class's movement spell: Blink, Charge… aim at the cursor |
| Playing (Co-Op) | Stand within **4 yd** of a downed ally for **3 s** | revive downed party member at 50% HP |
| Playing | **C** | unlock / lock the camera |
| Any | **G** | toggle the picture polish (`?grade=0` starts it off) |
| Playing | **mouse wheel** | zoom, from over the shoulder out to 70 yd |
| Playing | **drag** (camera unlocked) | swing and tilt the camera |
| Playing | **Esc** | pause |
| Playing | — | abilities cast themselves (no aim) |
| Level up | **1 / 2 / 3** (or click a card) | pick an upgrade (in Co-Op, locks in your choice and resumes once all living players pick) |
| Paused | **Esc** | resume |
| Game over | **Enter** (or **Play again**) | back to the menu |
| Any | minimap **+ / −** / minimize | minimap zoom / collapse |

The camera follows your local hero, locked top-down by default (laptop-friendly). **C** unlocks it
so a mouse drag swings and tilts it; **C** again snaps it back. In the menu it slowly orbits the
preview hero. Your race, gender, class and zone are remembered across reloads.
